## Features

- **Bilingual**: English and French, switchable from the navigation bar
- **Two-profile accent**: toggle between the AI & Data and Video Editing colour themes
- **Light and dark mode**: follows the system preference
- **Responsive**: designed for phones, tablets and desktops, including safe-area support for notched screens
- **Accessible motion**: animations respect `prefers-reduced-motion`
- **Fast and portable**: no framework, no dependencies; the only external requests are Google Fonts (Fraunces, Public Sans, JetBrains Mono)

## Tech stack

- HTML5, CSS3 (custom properties, grid, flexbox)
- Vanilla JavaScript (language toggle, theme and accent modes, scroll animations, carousels and lightbox)
- Google Fonts

## Deploy with GitHub Pages

1. Rename the HTML file to **`index.html`** (GitHub Pages serves this file by default).
2. Push it to the repository.
3. On GitHub, go to **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. After a minute, your site is live at the URL shown on that page.

For a cleaner address, name the repository `<your-username>.github.io`.

## Customising

Everything lives in one file:

- **Text and translations**: edit the content blocks and the French strings in the language script
- **Colours and fonts**: change the CSS variables at the top of the `<style>` block (`--bg`, `--ink`, `--amber`, `--teal`, ...)
- **Projects and videos**: copy an existing project or video card and update its title, description, tags and link
